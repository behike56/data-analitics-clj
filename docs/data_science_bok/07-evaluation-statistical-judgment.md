# 評価・統計的判断

予測の正確さ、推定の不確実性、仮説との整合性は、別の観点です。

| 概念 | 主な用途 | 読み方・注意点 |
| --- | --- | --- |
| RMSE | 回帰の予測性能 | 二乗誤差の平均の平方根です。目的変数と同じ単位で、同じ評価条件なら小さいほど誤差が小さいと読めます。 |
| 正解率（Accuracy） | 分類の予測性能 | 全件に占める正解件数の割合です。クラスの偏りが強い場合は、これだけでは性能を判断できません。 |
| 信頼区間 | 推定の不確実性 | 同じ手続きで標本抽出と区間作成を繰り返すと、指定した割合で真の値を含むように構成する区間です。 |
| p値 | 統計的仮説検定 | 帰無仮説と他のモデル仮定の下で、観測結果と同程度以上に極端な検定統計量を得る確率です。 |

代表的な予測指標の式は次のとおりです。

```text
RMSE = √{(1/n) Σ_i (y_i − ŷ_i)²}
正解率 = 正しく分類した件数 / 評価した総件数
```

将来の予測性能を確認するには、学習に使っていないデータや交差検証を利用します。学習データに対する誤差の小ささだけでは、未知のデータでの性能は分かりません。

95%信頼区間は、頻度主義では「算出済みのこの区間に真の値が95%の確率で入る」という意味ではありません。95%は区間を作る手続きの長期的な被覆率を表します。

p値は、帰無仮説が正しい確率や効果の大きさではありません。小さなp値だけで実務上の重要性や因果関係は判断できず、大きなp値でも「差がない」と確定するわけではありません。
