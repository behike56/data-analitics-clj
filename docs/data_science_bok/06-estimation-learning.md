# 推定・学習方法

## 推定基準と計算方法の違い

モデルの形を決めた後、未知の係数などをデータから求めます。このとき、「どの値をよいとするか」と「その値をどう計算するか」を分けます。

| 概念 | 役割 | 基本的な考え方 |
| --- | --- | --- |
| 最小二乗法 | 推定基準・推定方法 | 観測値と予測値の差の二乗和を最小にします。 |
| 最尤法 | 推定基準・推定方法 | 観測データに対する尤度を最大にします。 |
| 勾配降下法 | 数値最適化アルゴリズム | 目的関数が小さくなる方向へ、パラメータを繰り返し更新します。 |

最小二乗法の目的関数は、観測値を `y_i`、予測値を `ŷ_i` とすると、次の形です。

```text
二乗誤差和 = Σ_i (y_i − ŷ_i)²
```

最尤法では、観測データを固定してパラメータを変えたときの尤度を比較します。尤度は「パラメータそのものの確率」ではありません。独立な観測を仮定する場合、各観測の確率または確率密度の積で表せます。

勾配降下法は、最小二乗法の目的関数にも、最尤法の負の対数尤度にも使えます。したがって、この3つは同じ役割の代替手段ではありません。

## 正規分布・最尤法・線形回帰の関係

次の条件では、最尤法による回帰係数の推定と、通常の最小二乗法による推定が一致します。

```text
線形回帰：y_i = β₀ + β₁x_i1 + … + β_px_ip + ε_i
誤差の仮定：説明変数を条件として、ε_i は独立で平均0・共通分散σ²の正規分布
    ↓
負の対数尤度が、二乗誤差和に対応する形になる
    ↓
尤度を最大にする回帰係数 ＝ 二乗誤差和を最小にする回帰係数
```

正規分布を仮定する対象は、説明変数で条件づけた誤差です。説明変数や目的変数全体が正規分布であることを求めるわけではありません。また、最小二乗法の計算自体には正規性の仮定は必要ありません。

## ベルヌーイ分布・最尤法・ロジスティック回帰の関係

二値データの場合は、次のようにつながります。

```text
購入有無などの二値データ y_i
    ↓
説明変数 x_i の下で、y_i を成功確率 p_i のベルヌーイ分布でモデル化
    ↓
ロジスティック回帰で p_i を説明変数から表す
    ↓
通常は最尤法を基準に係数を推定
    ↓
負の対数尤度を、勾配降下法などの数値最適化で小さくする
```

成功確率が等しい独立なベルヌーイ試行を一定回数まとめた成功数は、二項分布に従います。ロジスティック回帰では、説明変数によって個々の成功確率が異なる場合も扱います。
