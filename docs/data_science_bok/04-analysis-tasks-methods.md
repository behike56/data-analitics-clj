# 分析タスク・方法

タスクは解きたい問題の種類、モデル・アルゴリズムはそのための具体的な表現や計算手法です。

| タスク・方法 | 主な目的 | 内容 | モデル・手法の例 |
| --- | --- | --- | --- |
| 回帰 | 関連・説明、数値予測 | 数値の目的変数と説明変数の関係を扱います。 | 線形回帰、回帰木 |
| 分類 | カテゴリ予測 | 入力からクラスや所属確率を推定します。 | ロジスティック回帰、分類木 |
| クラスタリング | 記述・探索 | 正解ラベルを前提とせず、類似したデータをまとめます。 | k-means |
| 統計的仮説検定 | 仮説の検討 | 帰無仮説とデータの整合性を、統計モデルの下で調べます。 | t検定、カイ二乗検定、回帰係数の検定 |
| 統計的因果推論 | 介入効果の推定 | ある介入を行った場合と行わなかった場合の差を扱います。 | ランダム化比較試験の解析、交絡調整、差の差法 |
