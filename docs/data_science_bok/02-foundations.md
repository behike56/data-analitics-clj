# 基礎

## データの性質

データの性質は、実際に観測された値を整理して把握するための知識です。主に記述統計と関係します。

| 分類 | 主な概念 | 例・着眼点 |
| --- | --- | --- |
| 変数の種類 | 量的変数、質的変数 | 身長は量的変数、血液型は質的変数です。 |
| 値の取り方 | 離散、連続 | 人数は離散的、時間は連続的な量として扱えます。 |
| 測定尺度 | 名義尺度、順序尺度、間隔尺度、比例尺度 | 血液型、満足度の順位、摂氏温度、身長がそれぞれの例です。 |
| 代表値 | 平均、中央値、最頻値 | データの中心や、よく現れる値を表します。 |
| ばらつき | 分散、標準偏差、四分位範囲 | 値がどの程度散らばっているかを表します。 |
| 分布の形 | 対称性、歪み、裾の長さ、山の数、外れ値 | ヒストグラムや箱ひげ図で確認します。 |
| 変数間の関係 | 共分散、相関 | 2つの変数が一緒に変化する傾向を調べます。 |

変数の種類と測定尺度は、関連しますが別の観点です。たとえば、摂氏温度と身長はどちらも量的変数ですが、摂氏温度は間隔尺度、身長は比例尺度です。

相関は因果関係を意味しません。また、一般的なピアソンの相関係数は線形の関係を捉えるため、相関係数が0でも関係がないとは限りません。

平均と標準偏差は、値を共通の尺度で表す「標準化」にも使います。データを変換する操作としての標準化は、[データの前処理・特徴量変換](08-preprocessing-feature-transformation.md)に配置しています。

## 確率・確率分布

確率分布は、確率変数がどのような値を、どの程度の確率で取るかを表します。データ生成の仕組みや不確実性をモデル化するための基礎です。

### 観測データの特徴と確率モデルの区別

たとえば身長データについて、「平均が170 cm程度」「左右対称に近い」は観測データの特徴です。「身長を正規分布でモデル化する」は、それを説明するために置くモデルの仮定です。

```text
観測された身長データ
    ↓ 記述する
平均・標準偏差・ヒストグラムなどの特徴
    ↓ モデル候補を考える
正規分布などの確率モデル
    ↓ データや背景知識と照合する
モデルの妥当性を確認・修正する
```

観測値の相対頻度で作る「経験分布」も数学的には確率分布です。そのため、観測された分布と、母集団・データ生成過程に仮定する分布を区別することが大切です。確率分布を単なるデータの特徴に限定して扱わないようにします。

### 代表的な確率分布

主な分布は、確率変数が取り得る値と、その生成の想定によって整理できます。

| 型 | 分布 | 表すものの例 |
| --- | --- | --- |
| 離散型 | ベルヌーイ分布 | 1回の購入有無など、0か1の結果 |
| 離散型 | 二項分布 | 独立で成功確率が等しい、固定回数の試行における成功回数 |
| 離散型 | ポアソン分布 | 一定の発生率などを仮定した、一定時間内の発生件数 |
| 連続型 | 正規分布 | 左右対称で釣鐘型の分布を持つ量や誤差 |
| 連続型 | 一様分布 | 有限区間内で確率密度が一定の量 |
| 連続型 | 指数分布 | 一定の発生率を持つポアソン過程での次の発生までの待ち時間 |

二値であることと、2つの結果が等確率であることは別です。ベルヌーイ分布では、1の確率を `p`、0の確率を `1-p` とし、`p=0.9` も可能です。

連続型では、ある1点の確率ではなく、区間に入る確率を密度の積分で求めます。観測データの平均・分散に対応して、確率モデルにも期待値・分散がありますが、標本から計算した値とモデル上の値は区別します。
