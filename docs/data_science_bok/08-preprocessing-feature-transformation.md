# データの前処理・特徴量変換

データの前処理・特徴量変換は、分析目的やモデルに応じてデータの表現を整える操作です。特徴量とは、モデルへの入力に使う変数のことです。回帰・分類・クラスタリングなど、複数の分析に共通して関わります。

## 知識体系上の位置づけ

標準化・正規化・無相関化・白色化は、「データの前処理・特徴量変換 → 数値データの変換」に配置します。尺度や長さをそろえる変換と、変数間の関係を整える変換に分けると、それぞれの役割が明確になります。

```text
データの前処理・特徴量変換
├─ 欠損値の処理
├─ カテゴリ変数の符号化
└─ 数値データの変換
   ├─ 尺度・長さをそろえる変換（スケーリング）
   │  ├─ 標準化
   │  ├─ Min-Max正規化（Min-Maxスケーリング）
   │  └─ ノルム正規化
   └─ 変数間の関係を整える変換
      ├─ 無相関化
      └─ 白色化：無相関化し、各変数の分散も1にする
```

標準化を理解するための平均・標準偏差は[基礎](02-foundations.md)にあります。標準化は、それらの値を使ってデータを変換する方法です。前処理はすべての分析で一律に行うものではなく、分析目的や採用するモデルに応じて選びます。

## 標準化の式と意味

ここでは、平均を引き、標準偏差で割る「標準化（zスコア変換）」を扱います。

$$
z_i = \frac{x_i - \bar{x}}{s}
$$

| 記号 | 意味 |
| --- | --- |
| $x_i$ | 変換前の各データの値 |
| $\bar{x}$ | 変換の基準となるデータの平均 |
| $s$ | 変換の基準となるデータの標準偏差（$s > 0$） |
| $z_i$ | 標準化した値 |

標準化した値は、「平均から標準偏差の何倍だけ離れているか」を表します。基準にしたデータを標準化すると、平均は0、標準偏差は1になります。標準偏差の計算では、変換前後で同じ定義（分散の分母を $n$ にするか $n-1$ にするか）を使います。

たとえば、平均60点、標準偏差10点の試験で80点を取った場合は、次のようになります。

$$
z = \frac{80 - 60}{10} = 2
$$

これは「平均より標準偏差の2倍だけ高い」という意味です。平均と同じ60点なら0、平均より10点低い50点なら−1になります。

## 正規化の意味と種類

「正規化」は文脈によって意味が異なります。この文書では、値の範囲をそろえるMin-Max正規化と、各観測のベクトルの長さをそろえるノルム正規化を区別します。いずれも、正規分布に変える操作を意味しません。

### Min-Max正規化

変数ごとに最小値と最大値を使い、基準データの値を0〜1に変換します。

$$
x' = \frac{x-x_{\min}}{x_{\max}-x_{\min}}
$$

たとえば、最小値20、最大値100のデータで60を変換すると、$(60-20)/(100-20)=0.5$ になります。最大値と最小値が同じ変数には、この式を適用できません。基準データの範囲外にある新しい値は、変換後に0未満や1より大きくなることがあります。

### ノルム正規化

各観測を複数の特徴量からなるベクトルとして扱い、その長さ（ノルム）で割ります。L2ノルムは、各成分の二乗和の平方根です。

$$
\boldsymbol{x}'=\frac{\boldsymbol{x}}{\|\boldsymbol{x}\|_2}
$$

たとえば、ベクトル $(3,4)$ のL2ノルムは5なので、変換後は $(0.6,0.8)$ となり、長さが1になります。ゼロベクトルは長さが0なので、この式では変換できません。

標準化やMin-Max正規化を変数ごと（データ表の列ごと）に行うのに対し、ここでのノルム正規化は観測ごと（行ごと）に行います。成分間の比率や方向を保ちながら、観測ごとの大きさをそろえる変換です。

## 無相関化と白色化

無相関化は、変換後の変数間の共分散を0にする操作です。白色化は、それに加えて各変数の分散を1にします。共分散行列とは、各変数の分散を対角成分に、変数間の共分散をそれ以外の成分に並べた行列です。

| 変換 | 整えるもの | 基準データでの変換後の特徴 |
| --- | --- | --- |
| 標準化 | 各変数の中心とばらつき | 平均0・分散1。変数間の相関は残ります。 |
| Min-Max正規化 | 各変数の値の範囲 | 最小値0・最大値1になります。 |
| L2ノルム正規化 | 各観測のベクトルの長さ | 各ベクトルのL2ノルムが1になります。 |
| 無相関化 | 変数間の共分散 | 共分散行列の対角以外が0になります。 |
| 白色化 | 変数間の共分散と各変数の分散 | 共分散行列が単位行列（対角が1、それ以外が0）になります。 |

これらは、分母が0になる場合などを除いた性質です。無相関化・白色化は一般に複数の変数を組み合わせて新しい変数を作るため、変数ごとの標準化とは異なります。

### 身長と体重の例

身長と体重に正の相関があるデータを考えます。標準化では、身長と体重をそれぞれ平均0・分散1にしますが、両者の相関は残ります。

PCA（主成分分析）による無相関化では、身長と体重を組み合わせて、互いに共分散が0となる新しい座標軸を作ります。さらに各軸の標準偏差で割ると、白色化できます。

```text
中心を引いた、斜めに伸びた楕円状の点群
    ↓ PCAによる無相関化：主な伸びの方向を座標軸に合わせる
座標軸に沿った楕円状の点群
    ↓ 各軸の標準偏差で割る
各軸の分散が1で、軸の間の共分散が0の点群
    └─ この一連の変換がPCA白色化
```

これは共分散による広がりのイメージです。任意の点群が実際に円形になるという意味ではありません。また、無相関は独立を意味せず、白色化後も非線形な依存関係が残ることがあります。

### PCAとの関係と基礎知識

無相関化・白色化の数学的な基礎には、共分散行列、固有値・固有ベクトルがあります。PCAは、共分散行列の固有ベクトルを使って新しい座標軸を作る手法で、無相関化に利用できます。PCAだけでは、通常、各軸の分散は1になりません。

共分散行列を $\Sigma=U\Lambda U^\mathsf{T}$ と分解した場合、PCAによる無相関化と白色化は次のように表せます。$\boldsymbol{\mu}$ は基準データの平均ベクトル、$U$ は固有ベクトルを列に持つ行列、$\Lambda$ は各軸の分散に対応する固有値を対角に持つ行列です。

$$
\text{無相関化：}\quad \boldsymbol{y}=U^\mathsf{T}(\boldsymbol{x}-\boldsymbol{\mu})
$$

$$
\text{PCA白色化：}\quad \boldsymbol{z}=\Lambda^{-1/2}U^\mathsf{T}(\boldsymbol{x}-\boldsymbol{\mu})
$$

無相関化後の共分散行列は $\Lambda$、白色化後は単位行列になります。白色化の式は、使用する固有値がすべて正の場合に適用できます。固有値が0の方向がある場合、元の全次元で共分散行列を単位行列にすることはできません。正の固有値に対応する方向だけを残すなどの対応が必要です。固有値が極端に小さい場合も、割り算によってノイズが増幅されることがあります。

PCAは次元削減にも使えますが、無相関化自体に次元削減は必須ではありません。ここで示したPCA白色化は白色化の一つの方法です。

## 分析での利用例

年齢と年収を使って顧客をk-meansでグループ化する場合、年齢を「歳」、年収を「円」で表すと、年収の数値の差が距離の計算を強く左右します。変数ごとに標準化すると、各変数の差を標準偏差に対する相対的な大きさで比較できます。

ただし、標準化によって各変数の業務上の重要性まで等しくなるわけではありません。変数の選択や重みづけは、分析目的に応じて判断します。

## 関連概念との違いと注意点

| 概念・条件 | 標準化との関係 |
| --- | --- |
| 正規分布 | 標準化しても正規分布になるわけではありません。中心とばらつきの尺度を変えても、分布の歪みなどの形は残ります。 |
| 標準偏差が0の変数 | すべての値が同じであり、式の分母が0になるため、この式では標準化できません。変数の除外など、扱いを別途決めます。 |
| 外れ値 | 平均と標準偏差は外れ値の影響を受けます。標準化だけで外れ値の影響が解消するわけではありません。 |

予測モデルの評価では、学習データだけで平均・標準偏差を求め、その値を検証・テストデータにも適用します。全データから求めると、評価用データの情報が学習側に入り込む「データ漏洩」が起こります。検証・テストデータを変換した後の平均・標準偏差は、必ずしも0と1にはなりません。

Min-Max正規化の最小値・最大値や、無相関化・白色化の共分散行列・変換行列も、学習データだけから求めます。評価用データではそれらを再計算せず、同じ変換を適用します。交差検証では、分割ごとに学習側のデータで求め直します。

確率変数にも、期待値 $\mu$ と標準偏差 $\sigma$ を使った標準化 $Z=(X-\mu)/\sigma$ があります（$0<\sigma<\infty$）。これは[確率・確率分布](02-foundations.md#確率確率分布)に関連する概念です。$X$ が正規分布に従う場合、その標準化によって $Z$ は標準正規分布に従います。観測データから計算した平均・標準偏差と、確率モデル上の期待値・標準偏差は区別します。
