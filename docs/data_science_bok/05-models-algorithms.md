# モデル・アルゴリズム

モデルの位置づけには、次のような関係があります。

- **線形回帰**：係数に対して線形な形で関係を表すモデルです。説明変数が1つなら単回帰、複数なら重回帰と呼びます。この文書の「重回帰」は重線形回帰を指します。
- **ロジスティック回帰**：二値の目的変数が1になる確率をモデル化します。名前に「回帰」が入りますが、分類にも使います。確率からクラスを決めるには閾値を設定します。
- **決定木**：条件分岐で予測するモデルです。分類木と回帰木があり、分類にも回帰にも使えます。
- **k-means**：各データを近い重心に割り当て、重心を更新するクラスタリングのアルゴリズムです。クラスタ数 `k` を指定します。

回帰モデルの係数を求めただけでは、因果効果は分かりません。因果解釈には、研究設計や交絡への対処など、追加の根拠が必要です。
